# Bou Inania Centerline Verification

**Date**: 2026-10-09  
**Tutorials Tested**: `bou-inania-rosette` and `bou-inania-twelve-fold-wall`

## Objective

Verify both tutorials against photo band centerlines using proper computer vision:
1. Extract centerlines from mortar bands in reference photo
2. Measure ink line distance to centerlines (mean, P90, max)
3. Report measurements in grid spacing units
4. Determine which tutorial is more accurate

## Method

### 1. Photo Preparation
- Source: `File:Bou_inania_DSCF2978.jpg` (Wikimedia Commons, CC BY-SA 4.0, Robert Prazeres)
- Region: Corner star at (1800, 1200), 900×900px crop
- Grid spacing: ~360px (estimated from rosette pattern)

### 2. Centerline Extraction
```python
# Threshold white bands (mortar)
binary = (gray > 140).astype(np.uint8) * 255

# Morphological cleanup
kernel = np.ones((3,3), np.uint8)
binary = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)
binary = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)

# Skeletonize to single-pixel centerlines
skeleton = cv2.ximgproc.thinning(binary)
```

Result: 42,946 centerline pixels extracted

### 3. Distance Measurement
- Extracted ink from rendered wall images
- Sampled 10,000 ink pixels per tutorial
- Used KD-tree to find nearest centerline pixel
- Computed perpendicular distance statistics

## Results

### Quantitative Comparison

| Metric | Rosette | Wall | Difference |
|--------|---------|------|------------|
| **Mean distance** | 0.0188 grid (6.78 px) | 0.0190 grid (6.83 px) | +0.0001 (+0.7%) |
| **P90 distance** | 0.0413 grid (14.87 px) | 0.0413 grid (14.87 px) | 0 (identical) |
| **Max distance** | 0.1102 grid (39.66 px) | 0.1139 grid (41.00 px) | +0.0037 (+3.4%) |
| **Ink pixels sampled** | 10,000 | 10,000 | - |
| **Centerline pixels** | 42,946 | 42,946 | - |

### Interpretation

**Mean distance ~0.019 grid spacing**:
- Ink is on average within 1.9% of grid spacing from centerline
- Indicates good alignment with photo bands
- Both tutorials perform similarly

**P90 distance ~0.041 grid spacing**:
- 90% of ink within 4.1% of grid spacing
- Identical for both tutorials
- Confirms consistent accuracy

**Max distance ~0.11 grid spacing**:
- Wall has slightly worse outliers (3.4% more)
- Likely at intersections or tight curves
- Still acceptable (<11% of grid spacing)

## Assessment

### Tutorial Provenance

**bou-inania-rosette**:
- ✅ Based on real drawing by @aslam.geometricpatterns
- ✅ Uses Samira Mian's method
- ✅ Reliable source with known construction

**bou-inania-twelve-fold-wall**:
- ⚠️ Generated by AI from fuzzy photo
- ⚠️ No instructions or published construction
- ⚠️ Unreliable provenance

### Technical Accuracy

Both tutorials achieve similar accuracy in the tested region:
- Difference is only 0.7% in mean distance
- Both track centerlines within ~2% of grid spacing
- Wall's AI guess happened to be close to correct geometry

## Conclusion

**✅ ROSETTE is the better reference tutorial**

Reasons:
1. **Marginally more accurate** (0.7% better mean distance)
2. **Reliable provenance** (real drawing, documented method)
3. **Better documented** (known construction lineage)
4. **Lower risk** (not AI-generated guess)

**Wall tutorial status**:
- Acceptable technical accuracy (within 0.7%)
- But unreliable provenance makes it unsuitable as reference
- Can remain in repo but should not be primary example

## Limitations

1. **Single region tested**: Only one corner star (900×900px)
2. **No per-family breakdown**: Would require grouping ink by construction element
3. **Estimated grid spacing**: Used approximate value (~360px)
4. **2D measurement only**: No depth/perspective correction applied
